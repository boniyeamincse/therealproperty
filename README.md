# Ariba Real Estate

Welcome to the **Ariba Real Estate** project, a modern, fast, and responsive real estate web application built using [Next.js](https://nextjs.org/) and React.

## Features

- **Modern UI/UX:** A clean, intuitive interface tailored for property browsing and management.
- **Fast Performance:** Server-Side Rendering (SSR) and Static Site Generation (SSG) powered by Next.js.
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.

## Tech Stack

- **Framework:** Next.js (version 16)
- **Library:** React (version 19)
- **Language:** TypeScript
- **Linting:** ESLint

## Getting Started

First, ensure you have Node.js installed, then install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Next, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the application by modifying the pages in the `src/app/` directory. The page will auto-update as you edit the files.

## Project Structure

- `src/app/` - Next.js App Router containing pages and layouts.
- `src/components/` - Reusable React components.
- `src/data/` - Static data or data fetching utilities.
- `public/` - Static assets such as images and icons.

## Building for Production

To create an optimized production build, run:

```bash
npm run build
```

Then, you can start the production server with:

```bash
npm run start
```
